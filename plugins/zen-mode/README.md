# Zen Mode

Hides the sidebar, terminal and chat with one key so it's just you and the code. Press it again to bring everything back exactly as it was.

## Usage

| Command | Keys |
| --- | --- |
| View: Toggle Zen Mode | Ctrl+Alt+Z |

The shortcut works even while the terminal has focus.

## Details

- Zen mode remembers which panels were open and restores just those.
- It doesn't change your saved layout: if you restart ocode in zen mode, your normal panels are back.
- You can still open panels while in zen mode (Ctrl+B, Ctrl+`, Ctrl+Alt+B). Pressing Ctrl+Alt+Z then restores the layout from before zen mode.
